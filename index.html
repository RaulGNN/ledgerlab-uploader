Ledger Lab Uploader

A private publishing tool for the Ledger Lab family of YouTube channels.

What it does

Ledger Lab Uploader is a command-line tool run by the channel owner on their own computer. It uploads educational personal-finance videos that the owner produced to YouTube channels the owner manages, and schedules when each video is published.

How it uses YouTube

  • It uses the YouTube Data API to upload videos and set their title, description, tags and publish time.
  • It reads the name and ID of the authorized channel only to confirm that each video goes to the intended channel.
  • It does not read, change or delete any other content, comments, subscribers or analytics.

Who can use it

The tool is not offered to the public. It is used only by the owner of the channels it publishes to.
